# 스토어 그래픽 제작 브리프 (클로드 디자인용)

이 파일을 클로드(Claude) 디자인 세션에 그대로 붙여넣고 "이 브리프대로 1번 에셋부터 순서대로 만들어줘"라고 요청하면 됩니다.
총 산출물: **스크린샷 8장 × 2개 언어(한/영) + 피처 그래픽 1장 × 2개 언어 = 18개 이미지**

- 관련 문서: [스토어 리스팅 개편안](store-listing-aso.md) (캡션 문구의 원본)
- 앱: OrderKiosk — 음성으로 햄버거 주문을 연습하는 키오스크 시뮬레이션 앱
- 포지셔닝: **"키오스크가 어려운 어르신을 위한 주문 연습 앱"** — 모든 디자인은 크고, 또렷하고, 친절하게

---

## 1. 공통 디자인 시스템

### 규격

| 에셋 | 크기 | 비율 |
|---|---|---|
| 스크린샷 (16장) | 1080 × 1920 px | 9:16 세로 |
| 피처 그래픽 (2장) | 1024 × 500 px | 가로 |

### 레이아웃 (스크린샷 공통)

```
┌──────────────────────┐
│   캡션 띠 (상단 22%)   │  ← 배경색 + 큰 흰 글씨 캡션, 중앙 정렬
│                      │
│  ┌────────────────┐  │
│  │                │  │
│  │  폰 목업 프레임   │  │  ← 둥근 모서리 폰 프레임 안에
│  │  (앱 화면 재현)   │  │     아래 "화면별 명세"의 UI를 재현
│  │                │  │
│  └────────────────┘  │
└──────────────────────┘
```

### 팔레트

| 용도 | 색상 |
|---|---|
| 캡션 띠 / 포인트 | 주황 `#FF6B35` (패스트푸드 키오스크 느낌) |
| 배경 (폰 프레임 뒤) | 크림 `#FFF4EC` |
| 앱 화면 배경 | 흰색 `#FFFFFF` |
| 본문 텍스트 | 진회색 `#2D2A26` |
| 봇 말풍선 | 연회색 `#F1F1F1` (왼쪽 정렬) |
| 사용자 말풍선 | 주황 `#FF6B35` + 흰 글씨 (오른쪽 정렬) |
| 버튼 | 주황 배경 + 흰 글씨, 모서리 둥글게 |

### 타이포그래피 원칙 (어르신 타겟 — 가장 중요)

- 캡션: 굵게, 최소 64px 상당. 한 줄 또는 두 줄.
- 앱 화면 내 텍스트도 실제 앱보다 약간 크게 재현 (읽히는 것이 우선, 픽셀 단위 재현은 불필요)
- 장식보다 대비. 흰 바탕 + 진한 글씨.

### 언어 규칙

- `ko` 버전: 캡션과 화면 내 UI 텍스트 모두 한국어
- `en` 버전: 캡션과 화면 내 UI 텍스트 모두 영어
- 파일명: `screenshot_ko_01.png` ~ `screenshot_ko_08.png`, `screenshot_en_01.png` ~ `screenshot_en_08.png`, `feature_graphic_ko.png`, `feature_graphic_en.png`

### 메뉴 데이터 (화면 재현에 사용할 실제 앱 데이터)

| 한국어 | 영어 | 단품 | 세트 |
|---|---|---|---|
| 빅맥 | Big Mac | 6,000원 | 8,000원 |
| 불고기버거 | Bulgogi Burger | 8,000원 | 10,000원 |
| 새우버거 | Shrimp Burger | 7,000원 | 10,000원 |
| 치즈버거 | Cheeseburger | — | — |
| 핫도그 | Hot Dog | 5,000원 | 6,000원 |

영어 화면 가격 표기는 `$6.00` 형태로 환산 표기 (실제 앱과 동일할 필요 없음).
음식 이미지는 단순한 일러스트/아이콘 스타일로 그려도 됨 (실사진 불필요).

## 2. 화면별 명세 (스크린샷 8장)

각 항목: 캡션(띠에 들어갈 문구) + 폰 프레임 안에 재현할 화면.

### #1 — 대표컷: 음성 채팅 주문

- **캡션 ko:** `말로 주문하는 키오스크 연습`
- **캡션 en:** `Practice kiosk ordering by voice`
- **화면:** 채팅 UI. 말풍선 3개 + 하단 중앙에 큰 마이크 버튼(주황 원형).
  - 봇(회색, 좌): ko `무엇을 주문하시겠어요?` / en `What would you like to order?`
  - 사용자(주황, 우): ko `불고기버거 세트 하나 주세요` / en `One Bulgogi Burger combo, please`
  - 봇(회색, 좌): ko `불고기버거 세트를 담았습니다.` / en `Added one Bulgogi Burger combo.`

### #2 — 전체 메뉴

- **캡션 ko:** `진짜 키오스크처럼 메뉴 고르기`
- **캡션 en:** `Pick from a real kiosk menu`
- **화면:** 상단 탭 4개 — ko `버거 · 사이드 · 음료 · 디저트` / en `Burger · Sides · Drinks · Dessert` (첫 탭 활성, 주황 밑줄). 아래 2열 그리드 메뉴 카드 4~6개(이미지 + 이름 + 가격). 위 메뉴 데이터 사용.

### #3 — 옵션 선택

- **캡션 ko:** `세트·단품 옵션도 미리 연습`
- **캡션 en:** `Combo or single — practice options`
- **화면:** 불고기버거 큰 이미지 + 이름. 아래 큰 선택 버튼 2개:
  - ko: `단품 8,000원` / `세트 10,000원`
  - en: `Single $8.00` / `Combo $10.00`

### #4 — 수량 선택

- **캡션 ko:** `수량 선택도 차근차근`
- **캡션 en:** `Choose quantity step by step`
- **화면:** 중앙에 크게 `−  1  +` (원형 버튼 2개 + 숫자), 위에 선택한 메뉴 요약(불고기버거 세트), 아래 확인 버튼 (ko `확인` / en `OK`).

### #5 — 포장/매장

- **캡션 ko:** `포장할까요, 먹고 갈까요?`
- **캡션 en:** `Dine in or to go?`
- **화면:** 봇 질문 말풍선 — ko `포장하시나요? 매장에서 드시나요?` / en `For here or to go?`. 아래 큰 버튼 2개 나란히 — ko `매장` / `포장`, en `For here` / `To go` (각 버튼에 간단한 아이콘: 쟁반 / 봉투).

### #6 — 결제 수단 (신뢰 메시지 핵심 컷)

- **캡션 ko:** `실제 결제는 없어요, 안심 연습`
- **캡션 en:** `No real payment — practice safely`
- **화면:** 결제 수단 선택 버튼들 (ko `카드 결제` / `모바일 결제`, en `Card` / `Mobile pay`). 화면 하단에 초록 체크 아이콘 + 작은 안내 문구: ko `연습용 앱입니다. 실제 결제가 일어나지 않습니다.` / en `Practice app — no real payment is made.`

### #7 — 주문 확인 (영수증)

- **캡션 ko:** `주문 내역 확인까지 완벽하게`
- **캡션 en:** `Review your order like a pro`
- **화면:** 영수증 스타일 리스트 2건 이상:
  - ko: `불고기버거 (세트) x 1 — 10,000원` (아랫줄 작게 `감자튀김, 콜라`), `치즈버거 (단품) x 1 — 6,000원`, 하단 굵게 `총 주문금액 : 16,000원`, 확인 버튼
  - en: `Bulgogi Burger (Combo) x 1 — $10.00` (아랫줄 `French Fries, Cola`), `Cheeseburger (Single) x 1 — $6.00`, `Total amount : $16.00`

### #8 — 주문 완료

- **캡션 ko:** `주문 완료! 이제 매장에서도 자신 있게`
- **캡션 en:** `Order complete!`
- **화면:** 중앙에 큰 주문번호 — ko `주문번호 : 1234` / en `Order number : 1234`, 위에 축하 아이콘(체크 원형 또는 폭죽), 아래 문구 ko `주문이 완료되었습니다.` / en `Order is completed.`, 처음으로 버튼.

## 3. 피처 그래픽 (1024 × 500, 2장)

- **구성:** 좌측 55% 텍스트 영역, 우측 45% 폰 목업(스크린샷 #1의 채팅 화면 축소판, 살짝 기울여 배치).
- **배경:** 주황 `#FF6B35` → 진주황 그라데이션, 텍스트는 흰색.
- **텍스트 ko:**
  - 메인 (굵게, 크게): `키오스크, 미리 연습하세요`
  - 서브 (작게): `실제 결제 없는 주문 연습 · 음성 주문 지원`
- **텍스트 en:**
  - 메인: `Practice kiosk ordering`
  - 서브: `Voice ordering · No real payment`
- 앱 아이콘이나 로고는 넣지 않아도 됨 (Play 스토어에서 아이콘이 별도 표시됨).

## 4. 제작 시 참고

- 목업은 실제 앱 화면의 픽셀 단위 재현이 아니라 **홍보용 재구성**입니다. 위 명세의 텍스트·구성만 지키면 디테일은 보기 좋게 다듬어도 됩니다.
- 단, 화면 내 언어와 캡션 언어는 반드시 일치시킬 것 (한국어 캡션 + 영어 UI 금지).
- 광고 배너는 목업에 넣지 말 것.
- 완성본은 Play Console 업로드 규격(스크린샷 최소 1080px, PNG/JPG)만 맞으면 됩니다.
